## 찍는 방법

- **소리까지 녹화해야 한다** — 점프 스케어 · 음량 줄어듦이 보여야 한다. macOS 기본 화면 기록(⌘⇧5)은 시스템 소리를 못 담는다 →
  **OBS**(「macOS 화면 캡처」 소스가 앱 소리까지 담는다)
- 노트북: MacBook Air M2 · 8 GB. CLIP을 켜면 확장 1.0 GB + 탭 0.55 GB라 **OBS 말고 다른 앱은 닫는다**. 장면마다 찍은 뒤
  `scareblock.stats()`의 `렌더끊김`을 확인하고, 늘었으면 다시 찍는다
- 안정적인 볼륨 **끔** · YouTube Premium(광고 없음) · 유튜브 음량 100%
- 콘솔은 DevTools를 **별도 창**으로 두고 화면 구석에 작게(OBS 창 캡처 소스 하나 더). 페이지에 붙인 콘솔은 끊김을 만든다(M1 10.07)
- 진행 막대가 필요 없는 장면은 `e5.prepare({ start, dur })`(진행 도우미)로 시작 · 끝을 맞춰 찍을 수 있다 — 같은 구간을 「끈 채 / 켠 채」 두 번 찍기 좋다
- 영상 출처(채널 · 제목)는 장면마다 화면 아래에 적는다. 클립은 짧게(장면당 30초 안)
